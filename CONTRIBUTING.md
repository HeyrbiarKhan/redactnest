# Contributing

Thank you for wanting to help.

**Code contributions are not accepted yet.** Pull requests from outside the
project are closed without review for now. That keeps one copyright holder,
so any later change to how RedactNest is licensed stays possible.

**Issues are welcome.** Bugs, ideas and questions all help, and anything about
how a document is redacted most of all. Please never attach a real document
you would not want made public, because issues are public too.
